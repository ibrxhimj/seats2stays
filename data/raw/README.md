# Raw competition data (not included)

The five files of the ATP 2026 DCT Abu Dhabi data pack go here. They are licensed for use within the
competition only, so they are not in this repository. `config.yaml` lists the expected names and their
SHA-256 checksums; the build stops if a file is missing or different.

| Key | File |
|---|---|
| flights | `flight_data.xlsx` |
| intl_train | `data_international_train.xlsx` |
| intl_test | `data_international_test.xlsx` |
| dom_train | `data_domestic_train.xlsx` |
| dom_test | `data_domestic_test.xlsx` |
